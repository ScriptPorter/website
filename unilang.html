Code at the Speed of Thought.

Born from the ScriptPorter project, Unilang is now a standalone, executable programming language. Write ultra-clean symbolic syntax (->, <-, ?(), ...) and run .unilang programs natively on Windows.

Why Unilang?

Minimalist Symbols. Maximum Expressiveness.

Designed to eliminate boilerplate and make logic crystal-clear with intuitive, lightweight symbolic constructs.

->

Arrow I/O Operations

Print values effortlessly with ->"Hello" and capture typed console input directly using <-(0) for integers, <-(0.0) for decimals, and <-(" ") for strings.

?()

Symbolic Conditionals

Replace verbose branching keywords with clean operators: ?() for if, ??() for else-if, and $() for else blocks.

...

Unified Loop Construct

Write while loops, count loops, and custom step loops using a single unified ellipsis syntax: (i=1, 10, 1)... { }.

<-{}

Clean Functions & Constants

Define functions concisely with sum<-{ ->a+b }<-a,b, call with (sum:5,10), and declare constants with fix.

F5

Interactive Desktop Environment

Includes ScriptPorter Unilang—desktop environment with one-click execution, inline console input, and instant termination controls.

.exe

Native Windows Integration

The Windows installer registers .unilang file associations automatically—double-click any script in File Explorer to open and run it directly.
