## 1. About ScriptPorter

ScriptPorter is a high-performance, multi-language desktop transpiler that translates a custom domain-specific language
'Unilang' into various standard programming languages. Instead of rewriting the core logic across different frameworks,
you can draft your algorithms once using Unilang, which acts as a universal blueprint, which can be used to generate 
production-ready source code for your target environment. The syntax of Unilang is very easy to understand and learn even for 
people with no technical background.

## 2. Supported Languages

ScriptPorter is capable of translating your Unilang code into 10 popular programming languages:

🔷Python
🔷Java
🔷JavaScript
🔷C#
🔷PHP
🔷Ruby
🔷Kotlin
🔷Dart
🔷Lua
🔷Groovy

## 3. Technologies Used

**Frontend: WPF (for final version), Flutter (for initial version)
**Backend: .NET
**Parsing: ANTLR4
**Other Technologies: JRE, VS Code, Visual Studio


## Getting Started

1. Run the installer (ScriptPorter_setup_x64.exe)
2. Launch ScriptPorter
3. Write your Unilang code in the left panel and you can see the live translation to the target language code in the right panel
4. For reference, sample projects are included, you can use 'File->Open' to view them
5. You can use the 'Help' for more information and Unilang documentation
